# CSCI160-CH08EXS
Programming Examples From Java Illuminated Book by Anderson and Franceschi  
**CH 8 EX 01** A demonstration of storing cellphone bill amounts in an array.  
**CH 8 EX 02** A demonstration of storing Auto objects (as seen in Chapter 7) in an array.  
**CH 8 EX 03** A demonstration of looping to print elements in an array.   
**CH 8 EX 04** A demonstration of using looping to store user input into an array.  
**CH 8 EX 05** A demonstration of using looping to add up all values in an array.  
**CH 8 EX 06** A demonstration of using looping to find the maximum value in an array.  
**CH 8 EX 07** A demonstration of using looping to store use input into an array.  
**CH 8 EX 08** A demonstration of how to check if two arrays are equal.  
**CH 8 EX 11 and 12** A demonstration of comparing two CellPhone type objects with bill information stored in arrays.

**CH 8 EX 18 and 19** A demonstration of the Insertion Sort process for sorting an array.  
**CH 8 EX 20** A demonstration of Binary Searching within an array.

**CH 8 EX 24** A demonstration of rolling a random 6-sided die 500 times and reporting the results with an array of length 7.
